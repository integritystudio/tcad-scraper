### TCAD API "Unexpected end of JSON input" Failures Fix (C1.6)

**Root Cause**: TCAD API returns truncated/malformed JSON responses for certain terms. Affected ~17% of batch jobs with all page sizes failing sequentially.

**Solution** (commit 8bb0ef5):
- **Per-fetch retry**: Jittered exponential backoff (50ms base, 2x growth) with max 3 retries per fetch attempt
- **Content-Length validation**: Byte-accurate mismatch detection via `Buffer.byteLength()` to catch truncation before parse
- **Request timeout**: AbortSignal.timeout(30s) per fetch to prevent hanging on slow/broken connections
- **Response timing**: Added diagnostics (start time, body length, parse duration) to error messages
- **Network resilience**: Explicit retry on ECONNRESET and other transient errors
- **Error aggregation**: Improved final error message showing last page size attempted + last error (vs first error)
- **Magic number cleanup**: Migrated hardcoded values to named constants (MAX_RETRIES, RETRY_DELAY_MS, MAX_TIMEOUT_MS)
- **Test fix**: Corrected pre-existing DST bug in scrape-scheduler.test.ts (March 2026 transition)
- **Coverage**: 8 new tests added (26 total in `tcad-api-client.test.ts`), 640/640 tests passing
- **Files**: `server/src/lib/tcad-api-client.ts`, `server/src/lib/__tests__/tcad-api-client.test.ts`, `server/src/schedulers/scrape-scheduler.ts`, `server/src/schedulers/__tests__/scrape-scheduler.test.ts`
