## March 6, 2026 — Backfill Script Documentation & Test Hardening

### Code Review Follow-up (2025 Backfill Scripts)

**Documentation & Comments**
- **CR-M2**: Documented opposite filtering strategies across backfill scripts
  - `backfill-2025.ts` / `backfill-2025-unsearched.ts`: `isSupersetOfSuccessful` skips candidates that EXTEND successful shorter terms
  - `backfill-2025-novel.ts`: `buildPrefixIndex` uses OPPOSITE strategy — skips candidates that ARE prefixes of longer already-searched terms
  - Cross-references added to explain rationale for each approach

- **CR-M3**: Added defensive comment to `COUNT(*)::int` cast in all 4 backfill scripts
  - `get2025Count()` uses `::int` to downcast PostgreSQL `bigint` so Prisma receives truthful `number` type
  - Comment notes: removing cast would break the type annotation without runtime error

- **CR-M5**: Fixed stale "GEO ID prefixes" comment in `backfill-2025-unsearched.ts`
  - Source actually mines description first-words, not GEO IDs
  - Updated section comment to match implementation

**Limitations & Edge Cases**
- **CR-L1 (03-02)**: Documented token-fetch-once-per-call behavior in `scrapePropertiesViaAPI`
  - Token fetched once per method call, reused across inner retry loop
  - Not a current bug (TOKEN_EXPIRED errors are handled by BullMQ retries), but fragile if error type changes

- **CR-L1 (03-06)**: Documented no-timeout limitation in `waitForQueueDrain` (all 4 scripts)
  - Drain loop has no maximum wait time — acceptable for CLI, can Ctrl+C if a job stalls
  - A permanently stalled BullMQ job will block indefinitely
