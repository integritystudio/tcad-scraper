### Key Changes

**L27–L28: Error Handling Boundaries**
- `naturalLanguageSearch`: try/catch wrapping Claude API call returns 503 ("AI service unavailable"); separate try/catch for DB calls returns 503 ("Database query failed")
- `scrapeProperties`: guard on `job.id` before `.toString()` returns 500 if job ID is missing

**L29: Distributed Rate Limiting**
- `canScheduleJob`: replaced in-memory `Map<string, number>` with `cacheService.get/set` using Redis TTL
- Rate limits now apply across all Render replicas (was process-local before)
- Survives server restarts via Redis persistence

**L30–L32: Input Validation & Parameterization**
- `naturalLanguageSearchSchema`: query string capped at 500 chars (Zod `.max(500)`)
- `api-usage.controller`: all `req.query` params (limit, offset, environment, days) use `typeof` guards instead of unsafe `as string` casts
- `$queryRaw` environment filter now parameterized via `Prisma.sql` tagged template for SQL injection prevention

**L31, L33–L34: Configuration Hygiene**
- `optionalAuth`: logs JWT verification failures at debug level for visibility
- Error handler uses `config.env.isDevelopment` instead of direct `process.env.NODE_ENV` reads
- `isDevelopment` now exclusive to NODE_ENV=development (was `!== "production"`)
- Auth skip logic extended to also trigger in `isTest` mode
