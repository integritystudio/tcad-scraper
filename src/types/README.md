# types

Frontend TypeScript types (`index.ts`):

- `Property` — property record as returned by the Workers API (snake_case fields)
- `AnswerType`, `AnswerStatistics`, `AnswerBoxState`, `AnswerBoxProps` — AI answer-box types

Shared cross-stack types live in `shared/types/`; Workers API types in `workers/tcad-api/src/types/`.
